# 波动光学计算机模拟汇报：PPT逐页大纲

建议题目：**基于统一复光场框架的波动光学计算机模拟**  
副标题：**衍射、泰伯效应、离轴全息与阿贝成像**

适用场景：课题组进展汇报或课程项目汇报。默认听众具备基础光学知识，但没有阅读项目代码。正文25页，备用7页，共32页；正文建议25～30分钟，按下表约25分35秒，讨论时间另计。

材料依据：项目当前源码、32个标准案例，以及小狗、小熊猫和猫的图片模拟结果。数据以已保存的JSON为准。所有“误差”“保留功率”须注明对应对象和比较基准。

## 一、汇报主线与制作原则

汇报主线：**建立具体物体模型 → 计算复光场 → 在传播或频谱面调制 → 展示可观察结果 → 用解析解和数值检查验证。**

四个模块分别回答四类问题：

| 模块 | 要回答的问题 | 核心输出 |
|---|---|---|
| 衍射 | 给定透过率和入射光，传播后光场如何变化？ | 近场、远场振幅/相位/强度 |
| 泰伯效应 | 周期物体在哪些距离重现自身结构？ | 沿程演化、整距/半距/分数自像 |
| 离轴全息 | 如何把物光信息编码进强度，再恢复复场？ | 强度全息图、频谱、重建幅相 |
| 阿贝成像 | 在频谱面控制不同频率，像面如何改变？ | 滤波器幅相、滤后频谱、像面幅相/强度 |

制作原则：

- 每页保留一个明确主题，正文通常不超过3～4个要点；推导放备用页。
- 每个实验按“输入—方法—结果—验证”讲述，不能只有彩色结果图。
- 全流程大图适合备查。正式投影优先选单张原图重新排列，避免整张流程缩小后文字无法辨认。
- 主图应保留坐标、单位、色标和传播距离。比较图应说明是否使用共同色标、是否按各图峰值归一化。
- 幅值、强度和相位必须分清；强度为复场模平方，相位在零振幅处没有定义。
- 自然照片使用“灰度指定为振幅透过率、初始相位设为零”的模型，不能称为测得动物的真实光学相位或三维形貌。
- 阿贝物理像面为倒像；已有照片滤波拼图为便于比较，转回物方方向并逐图归一化，须保留其说明。
- 小狗属于较早的图片示例；正文统一以小熊猫和猫作为三个模块的完整对照。标准案例计数不包含这些额外照片流程。

## 第03页｜输入图片、透过率与复光场

**页面目的**：提前解释自然图片如何进入模拟，避免把图片亮度误认为相位。

**页面上直接放的公式**：

$$U_0(x,y)=t(x,y)U_{\rm inc}(x,y),\qquad I=|U|^2$$

本次自然图片的具体定义：

$$U_{\rm inc}=1,\qquad t(x,y)=G(x,y),\qquad \phi_0=0$$

其中G是转灰度、归一化、缩放并嵌入计算网格后的图片；图片支集外t=0。

**页面文字**：灰度在这里被指定为振幅透过率；普通照片不能唯一提供真实光学相位；若是经过校准的强度数据，振幅对应√I。

## 第05页｜数值方法、采样与坐标

**页面目的**：说明结果有明确的物理坐标和数值条件。

**正文公式**：

$$U_z=\mathcal F^{-1}\{\mathcal F[U_0]H_z\},\qquad H_z=\exp[-i\pi\lambda z(\nu_x^2+\nu_y^2)]$$

**参数小表**：

| 场景 | 典型网格 | 采样间隔 | 说明 |
|---|---:|---:|---|
| 几何衍射 | 512×512 | 5 μm | 圆孔、方孔、单缝 |
| 泰伯光栅 | 512×512 | 1.25 μm | d=20 μm，每周期16样本 |
| 新增自然图片衍射 | 1536×1536 | 2.5 μm | 用2048网格作补零检查 |
| 新增自然图片全息/阿贝 | 1024×1024 | 2.5 μm | 与衍射保持相同物体图片尺寸 |

**必须强调**：远场坐标X=λzν；阿贝频谱面坐标ξ=λf₁ν。它们不能直接沿用物面dx。

**配图与版式**：上方一条传播公式，下方参数表，右下角用小框标注“场大小、采样间隔、输出坐标分别保存”。此页不展开四种传播算法的全部推导。

**讲述补充**：项目还提供角谱、夫琅禾费和单FFT菲涅耳；公共轴向载波相位按约定省略。FFT有限窗口需要补零和收敛检查。

**来源**：[数值约定](D:/桌面/衍射计算/docs/numerical-notes.md)、[LightPipes传播说明](https://opticspy.github.io/lightpipes/manual.html)。

## 第16页｜阿贝4f成像与物理倒像

**页面目的**：建立频谱面调制的光路位置和实际成像关系。

**主图**：[4f光路图](D:/桌面/衍射计算/outputs/workflows/21_阿贝成像_无附加滤波/03_计算过程/4f光路.png)，占页面上方约60%。

**主公式与参数**：

$$\xi=\lambda f_1\nu_x,\qquad H(\nu_x,\nu_y)=P\,M,\qquad P=\mathbf1_{\nu_x^2+\nu_y^2\le(\mathrm{NA}/\lambda)^2}$$

$$U_i(x_i,y_i)=-\frac1m U_0(-x_i/m,-y_i/m),\qquad m=f_2/f_1$$

**页面结论**：第一透镜形成空间频谱，公共频谱面加入滤波器，第二透镜形成倒像；振幅与采样按放大率缩放。

**建议讲稿**：“这里保留真实4f光路的两次正向变换和倒像关系。后面为直观比较而转正的拼图，只是显示方式，原始像面数据没有转正。”

## 备用A1（第26页）｜傅里叶坐标与物理归一化

**适用问题**：“FFT结果怎么对应屏上的位置？放大后为什么要改振幅？”

**页面放置内容**：

$$\Delta\nu=\frac1{N\Delta x},\quad X=\lambda z\nu,\quad\xi=\lambda f_1\nu,\quad\Delta x_i=(f_2/f_1)\Delta x$$

项目使用正交归一化DFT时，4f两次变换的系数为：

$$U_F=\frac{N\Delta x^2}{i\lambda f_1}\mathrm{DFT}_c(U_0),\quad U_i=\frac{N\Delta\xi^2}{i\lambda f_2}\mathrm{DFT}_c(HU_F)$$

$$\Delta\xi=\frac{\lambda f_1}{N\Delta x},\qquad P=\sum_{j,k}|U_{jk}|^2\Delta x\Delta y$$

**版式**：上方坐标映射，下方系数与功率；右侧一个物面/频谱面/像面采样表。

**答辩提示**：变换归一化和公共相位属于计算约定；输出坐标、像素面积和幅值系数必须配套。不能直接比较不同平面未乘像素面积的数组模平方之和。

**来源**：[传播核心](D:/桌面/衍射计算/optics_sim/core.py)、[阿贝模块](D:/桌面/衍射计算/optics_sim/abbe.py)。

## 备用A2（第27页）｜圆孔Airy解析解与远场判据

**适用问题**：“怎么确定远场近似成立？衍射结果与解析式是否一致？”

**页面公式**：

$$\frac{I(\rho)}{I(0)}=\left[\frac{2J_1(v)}v\right]^2,\quad v=\frac{\pi D\rho}{\lambda z},\quad N_F=\frac{a^2}{\lambda z}$$

圆孔标准案例D=200 μm、a=100 μm：z=2 cm时NF≈0.790；z=0.5 m时NF≈0.0316。

**配图**：[FFT与Airy中心截面](D:/桌面/衍射计算/outputs/workflows/01_圆孔衍射/05_验证/中心截面与基准.png)。左侧曲线、右侧参数与误差定义。

**补充文字**：矩形的远场振幅对应两个方向sinc因子的乘积；sinc(u)=sin(πu)/(πu)。项目用有限长单缝，不将其当作严格无穷长开口。

**答辩提示**：当前照片近场与远场采用不同传播距离；若把z解释为透镜焦距，傅里叶图样还可作为焦面图样理解，但要明确光路条件。

## 备用A3（第28页）｜泰伯距离的频域推导

**适用问题**：“为什么是2d²/λ？为什么半距平移半周期？”

**推导放四行**：

$$t(x)=\sum_nc_ne^{i2\pi nx/d}$$
$$U_z(x)=\sum_nc_ne^{i2\pi nx/d}\exp[-i\pi\lambda z n^2/d^2]$$
$$z=z_T=2d^2/\lambda:\quad e^{-i2\pi n^2}=1$$
$$z=z_T/2:\quad e^{-i\pi n^2}=(-1)^n,\quad U_{z_T/2}(x)=t(x+d/2)$$

**配图**：下方放输入、半距、整距三张截面，不再重复沿程大图。

**答辩提示**：该推导基于近轴、周期、相干模型；有限光栅和部分相干照明会影响自像。π相位二值光栅可能因对称性使不同复场对应相同强度，因此需检查相位或完整复场。

## 备用A4（第29页）｜合成复振幅透明片的完整设计

**适用问题**：“全息里的透明片到底是什么？输入灰度图是否包含相位？”

**定义**：设二维高斯函数g(x,y;xc,yc,σ)=exp{−[(x−xc)²+(y−yc)²]/(2σ²)}，坐标均用μm。

| 分量 | 中心(xc,yc) / μm | σ / μm | 用途 |
|---|---|---:|---|
| g₁ | (−88,−60) | 80 | 振幅权重1 |
| g₂ | (92,72) | 52 | 振幅权重0.65 |
| g₃ | (40,−120) | 36 | 振幅权重0.25 |
| gφ | (−48,0) | 80 | 相位系数1.1 rad |

$$t_h=\frac{g_1+0.65g_2+0.25g_3}{C}\exp[i(0.002x+1.1g_\phi)],\quad C=\max_{j,k}(g_1+0.65g_2+0.25g_3)$$

**配图**：[完整透过率图](D:/桌面/衍射计算/outputs/workflows/16_离轴全息复振幅透明片/01_输入图/透过率与复振幅表达式.png)，可裁取所需公式；[原始透明片示意](D:/桌面/衍射计算/outputs/workflows/16_离轴全息复振幅透明片/01_输入图/输入示意图.png)。

**答辩提示**：示意图的灰度是原始振幅透过率；相位由独立函数设计。实际进入全息传播的输入还经过圆形频带B，比较重建时应使用该带限输入。

## 备用A6（第31页）｜频谱面滤波器参数清单

**适用问题**：“滤波器有哪些？物理尺寸如何对应？调哪个参数？”

标准参数：f₁=f₂=100 mm、λ=632.8 nm、NA=0.03；物方孔径截止NA/λ≈47.408 mm⁻¹，近轴等效频谱面半径f₁NA=3 mm。

| 模式 | 标准案例设置 | 物理含义 |
|---|---|---|
| 无附加滤波 | M=1 | 有限NA基准 |
| 圆形低通 | r≤12 mm⁻¹ | 通过低频 |
| 圆形高通 | r≥12 mm⁻¹ | 阻断低频 |
| 环形带通 | 6≤r≤12 mm⁻¹ | 选择频带 |
| 高斯 | σ=12 mm⁻¹ | 平滑衰减高频 |
| 矩形 | 宽32、高12 mm⁻¹ | 各向异性通带 |
| 方向狭缝 | 宽4 mm⁻¹，长轴0° | 通过沿νx的频率 |
| 对称陷波 | 中心±(25,0) mm⁻¹，半径3 mm⁻¹ | 抑制指定级次 |
| 中心相位片 | 半径1.8 mm⁻¹，相移π/2 | 相衬 |
| 螺旋相位 | 拓扑荷l=1，零频样本遮挡 | 螺旋相位调制 |
| 相位斜坡 | 最终像面Δx=80 μm、Δy=0 | 频谱相位映射为像面位移 |
| 自定义复遮罩 | 两张灰度图分别映射振幅和2π相位 | 独立复调制 |

**页脚**：照片对比中的环形带通是4～12 mm⁻¹，与本表标准案例不同。自定义遮罩中心像素为零频，上方对应正νy；重采样覆盖整个频谱视场。

**答辩提示**：频谱面尺寸由ξ=λf₁ν换算；有限NA外的频率已经被截去，附加滤波器不能恢复它们。
