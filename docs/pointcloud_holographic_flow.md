# 三维点云全息完整流程与分深度再现（当前PPT）

按用户澄清，当前展示为：**三维点云输入 → 物光传播 → 实际全息记录或编码 → 光学/数字再现 → 不同深度的光强、振幅、相位**。最终不展示点云坐标反演、薄主面拟合、稀疏体或旋转动画；不包含原二维照片案例。

## 共同三维输入

猫、马、狼各3400点，原始PCD、来源、许可保存在 `data/pointcloud_holography/`。三维几何等比缩小至最长边0.7 mm，绕竖直轴固定旋转40°，中心距全息面3 mm。每点作为等振幅、初相位0的相干点源。逐点求和菲涅耳近似球面波，保留各自x、y、z及相对轴向传播相位，不把点云压成一张相位投影。

波长632.8 nm。1024²、1 μm网格求和，120/mm圆形物光带宽，恒定窗口频谱补零插值到2048²、0.5 μm记录网格。几何、点源相位、缩放及带宽均是明确的数值建模设置，不代表真实材质散射。模型不含遮挡、多次散射、像差和真实光学实验。

## 光学离轴全息：猫

1. 展示猫点云与到达记录面的物光振幅、相位。
2. 物光U与倾斜参考光R叠加，得到I_H=|U+R|²；理想薄振幅片t=I_H/max(I_H)。PPT直接展示保存的t图样，线性灰度。
3. 用共轭参考光R*照明，模拟物理4f光瞳选出会聚U*级次；PPT展示选级前频谱及实际光瞳位置。
4. 从同一全息片的再现场向前菲涅耳传播到三个已知深度，分别展示I、A、φ。

参考光振幅1.5、水平载频400.390625/mm，光学光瞳120/mm。FFT用于模拟物理选级与传播。再现只读保存全息片与标定，按已知增益校正，不读取输入点云。

## 计算全息：马

1. 展示三维马点云。
2. 直接求和三维点源波前，计算其会聚共轭复场。将振幅与相位分别量化为8位和256级，PPT直接展示实际调制图。
3. 这两张图共同表示本例的复振幅CGH，不是相机干涉光强；用均匀平面波照明理想串联振幅/相位调制器，再现实际量化的会聚波前。
4. 由同一组命令向前菲涅耳传播，展示三个深度的I、A、φ。

本组三维CGH选择点源求和与复振幅编码，实现与原二维NASA照片的GS纯相位目标约束不同；流程仍为数值生成、编码、照明和光学再现。没有在本例加入GS或WRP。再现只读取保存的调制命令及标定。

## 数字全息：狼

1. 展示狼点云与到达记录面的物光振幅、相位。
2. 与倾斜参考光R=1.5 exp(i2πf_c x)干涉，f_c=400.390625/mm。保存一张16位相机计数，PPT展示实际单幅全息图及其二维频谱。
3. 根据保存的光强标度还原I_H，对其做FFT，选择以(−f_c,0)为中心、半径120/mm的一级频带。逆FFT得到V≈U_H R*，再乘R/1.5²恢复全息面复振幅U_H。
4. 从同一帧恢复的复场按负距离数值菲涅耳传播，展示三个已知深度的I、A、φ。参考光已提供相位基准，无需四步相移或GS/HIO迭代。

当前单幅记录、标定、再现场位于 `outputs/pointcloud_direct/wolf/single-offaxis/`。由 `optics_sim.pointcloud_single_offaxis` 复用同一正向物光生成曝光，逆过程只重新读取保存的单帧计数和标定。16位理想量化，没有随机相机噪声。事后全息面复场相对L2误差约1.31×10⁻⁵，真值不参与重建。旧四步相移记录仅保留为历史试算，当前PPT不使用。

## 全息类型、传播算法与距离

三组均为**有限距离菲涅耳型全息**。点源到全息面采用连续三维坐标的近轴球面波求和，再现使用FFT菲涅耳传递函数：

`P_d(U) = IFFT[FFT(U) exp(−iπλd(fx²+fy²))]`

当前未使用角谱平方根传播因子或逐像素直接衍射积分。FFT用于数值传播和频谱选级，光学4f用于选取再现级次。当前没有把物光的傅里叶变换记录在透镜后焦面，故不因使用FFT而称为傅里叶全息。

| 案例 | 物点距全息面 / mm | 展示的深度d / mm | 再现传播 |
| --- | --- | --- | --- |
| 光学离轴，猫 | 2.772–3.242 | 2.910、3.076、3.193 | 共轭照明选出U*后，+d |
| 计算全息，马 | 2.774–3.230 | 2.830、3.012、3.156 | 调制器产生U*，+d |
| 数字全息，狼 | 2.773–3.229 | 2.864、3.064、3.193 | 解调恢复U，−d |

表中d为正的物距大小。所有距离均为已知参数，没有自聚焦搜索。光学再现与CGH的光学传播在电脑中模拟。CGH采用点源求和及双调制器复振幅编码，未使用GS或WRP。

单幅离轴解调参考：[Liebling、Blu、Unser，Complex-wave retrieval from a single off-axis hologram，JOSA A21,367–377(2004)](https://opg.optica.org/viewmedia.cfm?seq=0&uri=josaa-21-3-367)，[Cuche等，Optics Letters24,291(1999)](https://doi.org/10.1364/OL.24.000291)。

## 三种深度结果的显示

- I=|U|²，三个深度使用共同峰值Ip归一，显示γ=0.35。
- A=|U|，使用Ap=√Ip归一，显示γ=0.50。未变换数组始终满足I=A²；显示图因γ不同不能直接按灰度平方比较。
- φ=arg U，固定−π至π线性色标，无暗区掩膜、真值相位对齐或解包裹。

三个距离预设为输入深度的12%、50%、88%分位，用于已知距离再聚焦。每组同一记录/命令用于所有距离，裁剪到相同640 μm方形物体窗口，没有把输入点云重新放入恢复图。相干点源叠加产生颗粒，其他深度的离焦贡献仍然存在。

## 输出与复现

`optics_sim.pointcloud_direct` 生成原始记录及标定；`optics_sim.pointcloud_process_figures` 仅从这些记录重放，并绘制当前PPT的流程图与深度结果。正向参考复场只用于说明“记录的物光是什么”，不用于再现计算。

每个 `outputs/pointcloud_direct/{case}/full-process/` 包含：

- `recording-object-field.png`：正向记录面物光振幅与相位。
- 猫：`actual-hologram-and-replay.png`，保存的全息片图样与光学选级频谱。
- 马：`actual-cgh-commands.png`，保存的振幅/相位调制图。
- 狼当前位于 `single-offaxis/full-process/`：`actual-single-hologram-and-spectrum.png`，保存的单帧相机全息图及所选频谱一级。
- `depth-intensity.png`、`depth-amplitude.png`、`depth-phase.png`：各深度三种量的再现结果。
- `replay-fields.npz`：从保存数据得到的再现场、三个深度的复场及距离。
- `display.json`：共用标度、γ、相位范围与掩膜约定。

```powershell
$env:OPENBLAS_NUM_THREADS='4'
$env:OMP_NUM_THREADS='4'
& .venv/Scripts/python.exe -m optics_sim.pointcloud_single_offaxis
& .venv/Scripts/python.exe -m optics_sim.pointcloud_process_figures
```

早期层析与点坐标反演作为独立试算保留在各自目录，当前PPT与本流程不使用其结果。
