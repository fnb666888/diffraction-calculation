# 阿贝成像模块设计与验收

本次在现有三个实验之外增加相干照明的4f阿贝成像，复用Grid、Plane、Result、输入表达式及全流程导出。范围按当前项目的独立模块与案例规范确定，直接完成实现、验证和示例。

## 需求与验收

1. 当选择阿贝成像时，命令行和桌面界面应允许设置物体、波长、采样、两个焦距、物方NA及频谱面滤波器。
2. 当设置频谱滤波时，应提供圆形低通、高通、环形带通、高斯、矩形、方向狭缝、对称陷波、中心相位片、螺旋相位、相位斜坡及自定义振幅/相位遮罩；无附加滤波作为基准。
3. 每种示例应独立保存物体透过率、输入幅相、4f光路、频谱及滤波器幅相、滤后频谱、倒像幅相和强度、验证与NPZ数据。
4. 在NA覆盖全部离散频率、H=1时，输出应满足Uimg(xi,yi)=-(1/m)U0(-xi/m,-yi/m)，m=f2/f1；放大后积分功率守恒。
5. 对被动滤波器，输出功率不得超过无滤波有限NA基准；纯相位滤波保持基准功率。由实际频谱预测的传输功率应与像面功率一致。
6. 方向滤波/陷波应能选择或抑制指定傅里叶级次；相位片应能把弱相位物体转为强度对比。

## 计算约定

- 物面位于L1前焦面，公共频谱面在L1后焦面/L2前焦面，像面在L2后焦面。频谱物理坐标ξ=λf1νx、η=λf1νy。
- 使用SciPy提供的中心化、正交归一化FFT；两次正向傅里叶变换产生倒像，保留1/m振幅标度，省略公共轴向载波相位。
- 第一变换UF=NΔx²/(iλf1) DFTc(U0)；第二变换Ui=NΔξ²/(iλf2) DFTc(UF·P·M)。物方相干孔径P=1[νx²+νy²≤(NA/λ)²]；滤波器M在该孔径内调制复振幅。
- 计算栅格为周期边界，视场与采样须解析物体及截止频率。超过Nyquist的孔径按离散网格可表达频率处理并记录诊断。
- 照片灰度定义为振幅透过率或相位延迟，均是指定模型；相干图像处理不推断照片的真实相位。
- 自定义滤波图全幅对应当前离散频谱视场，重采样至n×n；振幅灰度→[0,1]，相位灰度→[0,2π]。图上方对应正νy，图像中心对应零频。
