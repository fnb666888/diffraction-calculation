# 真实图片的 CDI 反演

当前汇报的衍射部分采用真实照片 CDI，不使用独立合成靶标。结果入口是 `outputs/cdi_image/red_panda/index.html`。

## 复现

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m optics_sim.cdi_image --image "照片.jpg" --output "outputs/cdi_image/photo"
```

可用 `--samples`、`--n`、`--iterations` 调整图片最长边、补零网格和每个初值的迭代次数。默认分别为 80、256 和 2000。

## 物理模型和反演输入

照片灰度 `G` 被指定为实非负振幅，物体初始相位为零。物体光强为 `G²`，支集外物体为零。保持照片长宽比后，将其嵌入补零网格。

正向模拟生成 `ID = |DFTc(U0)|²`，DFT 采用正交归一化。焦面坐标以 `X = λ f ν` 换算，默认波长 632.8 nm、焦距 1 m。强度采用任意单位，不作为经过探测器标定的绝对照度。

反演函数只接收测量强度与矩形支集，并施加实非负约束。支集使用已知图片包围尺寸，各边外扩 3 像素。支集不读取原图内部轮廓或灰度。该先验是模拟条件，实际实验需要独立给定或估计。

## 迭代与评价

- HIO 反馈参数为 0.9，每个初值运行 2000 步，最后 50 步使用 ER 精修。
- HIO 使用随机种子 7、17、27，按测量傅里叶模相对残差选择结果。
- ER 的 seed=7 结果用于当前例子的对照，两者的迭代预算相同。
- 原图不参与迭代或随机种子选择。在恢复结束后，才用于消除平移、共轭反演与全局相位歧义，以及计算物体误差。
- 傅里叶模残差只评价与测量的一致性，物体误差另行报告。

这是完整测量、无噪声、已知有限支集及实非负物体条件下的数值例，不保证任意复物体的唯一恢复。

## 保存内容

`06_数据/data.npz` 保存模拟真值、测量强度、支集、各随机初值结果、未对齐恢复、评价对齐恢复、ER/HIO 残差曲线和坐标。`metrics.json` 记录误差、选择规则与评价对齐方式，`配置.json` 保存参数。

所有光强图均为线性灰度。弱条纹不加增益、γ 或对数增强。收敛曲线使用对数误差轴，表示残差跨数量级的下降。

算法参考：J. R. Fienup, *Phase retrieval algorithms: a comparison*, Applied Optics 21, 2758–2769 (1982), DOI: 10.1364/AO.21.002758。
