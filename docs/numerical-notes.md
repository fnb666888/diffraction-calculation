# 数值约定与模型范围

原始方案归档于 [plans/](plans/)，以下记录当前实现采用的约定与修正。

## 数值约定和对执行方案的修正

1. **FFT 排列一致。** 原骨架用中心化频率 H 乘未中心化 FFT，会产生错误。框架统一区分中心化变换和未移位传递函数，LightPipes 与 SciPy 双向传播交叉校核。去除公共轴向载波 `exp(ikz)`，保留相对相位。
2. **泰伯周期。** `zT=2d²/λ`。半距像平移半周期；固定横坐标的强度通常不是 zT/2 周期。纯相位输入应同时检查复场，而不是仅检查常数强度。解析基准使用整数周期窗口；有限截断光栅另算并报告中心与边缘误差，不把理想周期结果冒充有限光栅结果。
3. **离轴采样。** 一维载波方向中，物光谱半径 B 对应零级自相关带宽 2B，保守圆形带宽分离要求 `3B < |fc| < 1/(2dx)-B`。默认物体先通过明确声明的有限NA圆形频谱孔径，保存滤波前后真值及保留功率。并非任意未经带限的物体都能完全重建。
4. **参考角与条纹抽样。** `dx=5 μm、λ=632.8 nm` 时，5°参考角的载频超过 Nyquist；默认1.5°。默认对载频取最近FFT格点，模拟周期窗口内整数条纹。可将 `snap_carrier=false` 研究非整周期泄漏；可将 `strict_sampling=false` 探索级次重叠和混叠，此时重建误差会如实输出。
5. **二维孪生像。** 分离后共轭实像与二维物体可以具有相同强度，复场相位共轭。三维凹凸与视差反转超出当前二维透明片模型，不能要求二维孪生像强度相关性必然低。
6. **四步相移符号。** 采用 `R=A exp(+iφ)`，复场为 `[(I0-Iπ)+i(Iπ/2-I3π/2)]/(4A)`，四幅强度同时给出振幅和相位；无须另测物光振幅。
7. **角谱与倏逝波。** dx 大于 λ/2 并非所有角谱算法的普遍硬性限制。本实现显式处理传播/倏逝分量，正向取物理衰减分支，反向将倏逝分量投影掉，避免不稳定指数放大；此时反向传播不再能恢复已丢失的倏逝信息。
8. **像差补偿范围。** 演示使用记录面位置的薄相位屏：共光路参考消除相位屏，已知相位屏数值逆补偿，共轭波经同一屏相消。不能由这一模型推断任意未知体散射介质均可补偿。
9. **CDI 的先验和歧义。** HIO/ER 仅获得强度及支集/非负先验。真值在结束后评价，允许平移、全局相位和共轭反转对齐；输出同时保留原始解。收敛不保证对所有物体和种子成立。
