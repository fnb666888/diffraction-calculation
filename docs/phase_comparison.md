# 同一照片的初始相位对比

输入为小熊猫照片的归一化灰度振幅 A。基准为 U=A，新条件为 U=A exp(iφ)，其中

φ(x,y)=1.2 sin(2π·8x/W) sin(2π·8y/H)。

x、y 以照片有效矩形像素区域的中心为原点，W、H 是当前采样下照片的宽、高。
CDI、全息和阿贝统一使用512×341像素照片，像素间距2.5 μm，补零到1024×1024；物面照片宽1280 μm、高852.5 μm。三个模块的输入复振幅及空间坐标逐点相同，宽、高方向都包含8个周期。此相位是明确规定的数值模型，
不能解释为从照片中测得了小熊猫的真实光学相位。施加相位前后，输入振幅和光强保持一致。

## 计算

在项目根目录运行：

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
& '.venv/Scripts/python.exe' -m optics_sim.phase_comparison --iterations 3000 --support-margin 0
& '.venv/Scripts/python.exe' -m optics_sim.phase_comparison_figures
```

数据与图像在 `outputs/phase_comparison/red_panda/` 中。
默认依赖已有小熊猫全息、阿贝的原始 npz 与配置；CDI直接读取相同的输入复振幅，保留全息和阿贝的物理参数和光学滤波器。
脚本不修改或删除原始结果。

## 各模块的比较条件

- CDI：两组均使用照片已知的512×341像素矩形支集（外扩0像素），允许复振幅，不使用实非负物体先验。支集仅来自已知的外部矩形尺寸，不使用原图像素内容或初相位。随机种子为7、17、27，每个3000次HIO，最后50次ER精修。只按衍射光强的傅里叶模残差选取结果。真值仅在选取后用于评价及平移、共轭、全局相位歧义对齐，平移包含亚像素坐标原点偏移。亚像素对齐采用保留傅里叶模的周期傅里叶平移，不参与重建或初值选择。旧的单独CDI输入页面已删除。先前80×53输入的结果备份于diagnostics/previous_80px，不再用于PPT。较宽支集的中间计算另存于diagnostics/loose_support。
- 全息：对输入复振幅施加原有限带宽模型，传播到记录面，与同一倾斜参考光干涉，再从各自全息光强分离一级并反向传播。重建目标是有限带宽之后的物面复振幅。
- 阿贝：保持原NA，对比无附加滤波、圆形低通和圆形高通，低通与高通的截止频率均为12000/m。保存物理倒像，并另存转正以便比较的结果。无附加滤波且带宽足够时，相位变化可以不显著改变像面光强。

## 显示

光强使用 γ=0.30 的显示增强，同一比较组共用强度参考值，不改动复数数据。
相位采用固定 [-π,π] 色标，完整显示照片区域，不屏蔽暗区。PPT中的相位RMSE也统计完整照片区域。原始metrics.json保留算法评价定义和原始指标。
全息二维频谱使用共同参考值及对数显示。没有新增局部条纹图。

## 单独重新计算统一输入的CDI

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
$env:OMP_NUM_THREADS = '1'
& '.venv/Scripts/python.exe' -m optics_sim.cdi_shared_input --iterations 3000 --backend cpu
& '.venv/Scripts/python.exe' -m optics_sim.phase_comparison_figures
```

计算每250步保存断点；同一输入、随机种子和迭代预算可直接续算。支持可选CuPy/CUDA后端。本次完整数据以complex128计算，零相位组使用CPU，正弦相位组使用相同迭代公式的CUDA实现。两组各3个随机初值，均3000步，末50步ER。

CDI图只展示中心约±30/mm频区，避免零填充后的高频空白挤占图幅；反演始终使用完整1024×1024衍射光强。两组衍射图共用归一化参考及γ=0.30，不改变原始数据。
