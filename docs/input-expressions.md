# 输入透过率与复振幅的表达约定

每例公式按其真实构造与参数生成，绘制在 `01_输入图/透过率与复振幅表达式.png`、输入幅相图及全流程中。`input_models.py` 负责公式及独立数值求值；导出前将其与保存的实际输入复场比较，相对误差必须小于1e-12。

公式图的空间长度统一为 μm，频率为 1/μm；代码数组仍使用SI单位。指示函数在条件满足时为1，否则0。图中省略公共轴向载波，与共用传播框架的复包络约定一致。

## 几何孔径

- 圆孔：`t_c(x,y)=1` 当 `x²+y²≤a²`，否则0；默认 `a=100 μm`。单位平面波照明时 `U0=t_c`，不是未知的振幅/相位占位函数。
- 方孔：`t_s=rect(x/200)rect(y/200)`；单缝：`t_l=rect(x/200)rect(y/1000)`，长度以 μm 表示。
- 方孔和单缝的网格边缘采用像素平均：`w_a(u)=clip((a/2-|u|)/dx+1/2,0,1)`，真正送入FFT的是 `U0[k,j]=w_ax(xj)w_ay(yk)`，与连续透过率分别写明。

## 图片、光栅与CDI

- 振幅图片使用实际灰度矩阵 `G=gray/255`；相位图片使用支集内 `exp(i2πG)`，支集外0。图中给出实际缩放尺寸与嵌入索引，不虚构闭式解析图片。
- 当前二值光栅为 `b(u)=1_{frac(u/d+1/2)<η}`。默认 `d=20 μm、η=0.5`，通光段是每个周期的前半段，与代码原点一致。
- 正弦振幅光栅为 `[1+cos(2πu/d)]/2`；相位光栅为 `exp(iφdepth b(u))` 或 `exp(iφdepth s(u))`；二维振幅取乘积，二维相位延迟取两方向相位和。
- CDI靶标明确写出三个矩形区域、透过率0.8/1/0.5和覆盖顺序。

## 全息与扩展光场

合成透明片展开为三项高斯振幅和实际相位函数，并列出各中心、宽度和采样归一化常数。全息的实际输入场再经已知有限NA频谱孔径：`U0=IFFT(PB·FFT(t))`，不能把透明片透过率与带限场等同。

曲率入射明确写出二次相位和曲率半径；双光栅分别列出20/20.8 μm周期的透过率。部分相干输入逐模态为 `t_g exp(i2πfm x)`，幅相图对应第一模态，总强度没有单一相位。

离轴参考波使用实际FFT格点载频；四步相移写出同轴参考的四个相位；薄屏补偿给出 `tW=exp(iW)`、相位屏归一化和随机种子。
