# 三组点云全息与可旋转数值重建

## 打开结果

双击 `outputs/pointcloud_holography/index.html`，普通浏览器即可离线使用，无需安装软件或联网。

- 拖动旋转重建体，滚轮缩放，双击复位；也可自动旋转。
- 三组分别为猫（光学离轴全息）、马（复振幅计算全息）、狼（相移数字全息）。
- 切换采集角度，可看全息记录与恢复的物面相位投影；马案例额外展示计算出的振幅、相位调制图。
- 可切换三个方向的内部切片。橙色“输入点云参考”默认关闭，仅用于对照，不参与重建显示。
- 每组的 `reconstructed-rotation.gif` 是重建体旋转投影动画，可用于汇报。

## 本次实际做了什么

要让完整物体在重建后旋转，本次增加了**多角度全息层析**：绕竖直轴采集0°至178°、间隔2°的90个方向，恢复相位投影后做滤波反投影。交互页旋转的是从这些记录恢复的96³三维数值体。没有把输入点云直接当作重建结果，也没有在每次拖动时重新旋转输入再生成全息图。

这是对三个全息模块的三维扩展。单角度的全息数值传播仍然只恢复该角度的波前；**一张记录不能凭空补出全部背面**。这里没有把单张全息图宣称为360°物体扫描。

### 输入物体与物理近似

三份公开PCD各有3400点，来自PCL的Implicit Shape Model教程，教程注明点云借用自Ohio数据集。原文件、下载地址、SHA-256和PCL许可保存在 `data/pointcloud_holography/`。数据来源：[PCL教程](https://pointclouds.org/documentation/tutorials/implicit_shape_model.html)、[PCL数据仓库](https://github.com/PointCloudLibrary/data)。

将点云几何缩小到384 μm数值窗口，三线性散点栅格化后用σ=0.9体素高斯平滑，形成**透明弱相位表面密度** Δn(x,y,z)。这不是填实的动物实体，不包含真实材质、遮挡、反射散射或多次散射；Δn是演示设置，不是实测折射率。

采用直线投影近似：φθ(x,y) = k ∫ Δnθ(x,y,z) dz，物面透射场 Uθ = exp(iφθ)。物体内部不做衍射传播；从等效物面到记录面的传播使用标量角谱法。各物体密度预先缩放，使所有角度最大相位为1.8 rad，小于π，因此恢复相位无需解包裹。

| 参数 | 设置 |
| --- | --- |
| 波长 | 632.8 nm |
| 三维体素 | 96³，间距4 μm |
| 记录面 | 512²，间距2 μm |
| 等效物面至记录面 | 3 mm |
| 角度 | 90个，0°至178°，间隔2° |
| 相机/记录片离散化 | 理想16位量化，无光子/读出噪声 |
| 相移 | 0、π/2、π、3π/2，理想精确相移 |
| 反演 | 相位投影 + Hann窗斜坡滤波反投影 |

多角度相位投影进行层析有文献依据，例如 [Tomographic flow cytometry by digital holography](https://www.nature.com/articles/lsa2016241.pdf)。本代码采用其中适用的投影层析思路，不声称复现文中实验系统，也不是完整的衍射层析逆散射求解。

## 三条全息流程

### 1. 猫：光学离轴全息 + 数值层析

1. 计算各角度物面透射场，角谱传播3 mm。
2. 用55 mm⁻¹圆形物光带宽模拟物理光瞳，与水平载频180.664 mm⁻¹的倾斜参考光叠加，记录 I = |U + R|²。每角度一张，共90张。
3. 保存为理想振幅全息片，使用原参考光照明，模拟4f物理光瞳选出所需级次。FFT在这里计算光学选级，不是把光学再现偷换成数字频谱截取后宣称实物实验。
4. 模拟获取再现复场，按已知3 mm逆传播，取相位，再进行多角度层析。

因此它是“光学记录/再现流程的模拟 + 数字读出与层析扩展”，不是纯粹只靠肉眼观察的光学全息实验。物光带宽与再现光瞳会损失细节。

### 2. 马：复振幅计算全息 + 光学再现 + 数字层析

1. 从点云相位投影计算记录平面复场 U = A exp(iφ)。
2. 振幅归一后量化为8位，包裹相位量化为256级，分别保存为调制器命令。
3. 模拟均匀平面波照明、理想串联的振幅与相位调制器，形成实际量化后的再现复场。
4. 对再现场做四步相移数字采集，每角度4帧，共360帧。
5. 仅由保存的相机计数恢复复场，逆传播恢复相位投影，层析获得三维体。

这一组采用**理想双调制器复振幅编码**，没有使用GS迭代或WRP；它与原PPT中单平面GS纯相位全息例子不同。振幅调制、相位调制和后续数字采集都明确模拟，没有将目标图直接写入重建结果。

### 3. 狼：四步相移数字全息 + 数值层析

1. 角谱传播得到物光，与参考光在记录面干涉。
2. 四次改变参考光相位，保存16位相机光强，共90×4=360帧。
3. 按已知曝光标度把计数还原为光强，由 U = [(I0−Iπ) + i(Iπ/2−I3π/2)] / (4Ar) 恢复记录面复场。
4. 按已知距离角谱逆传播，取相位，换算为线积分，再层析重建三维Δn。

没有自聚焦，传播距离使用已知标定值。理想相移、无噪声的条件使本组相位误差很小，不能直接代表真实实验精度。

## 反演独立性与结果

`reconstruct()` 只接收 `recordings.npz`、`calibration.json` 与输出目录，不读取点云或 `input-reference.npz`。标定包含波长、采样间距、距离、参考光、采集角度和物面ROI。相位转线积分使用 k×体素间距；FBP没有使用真值支持域、真值相位解包裹、平移配准或事后拟合增益。真值只用于建模和计算误差。

| 案例 | 相位投影相对L2误差 | 原始三维体相对L2误差 | 三维体Pearson相关系数 |
| --- | ---: | ---: | ---: |
| 猫·光学离轴 | 9.45% | 28.97% | 0.964 |
| 马·复振幅CGH | 2.66% | 22.51% | 0.980 |
| 狼·相移数字 | 0.00419% | 19.99% | 0.986 |

三维误差包括有限角采样、插值、96³离散化和FBP平滑的误差。三组点云和记录条件不同，表格用于说明各案例恢复程度，不能作为三种方法优劣排名。

原始重建体保留正负值；背景会有小幅负振铃。交互图只显示正值，采用8位峰值归一化显示缓存和可调体素阈值；该操作不改变保存的浮点重建体。切片和GIF用γ=0.35改善可见度，恢复相位按0至1.8 rad线性灰度显示。全息记录预览做降采样，计算仍用512²原始记录。图中的点云参考是单独的输入对照。

## 文件与复现

- `recordings.npz`：16位相机/全息片记录；CGH另含8位振幅、相位命令及已知增益。
- `calibration.json`：模型和采集参数。
- `reconstructed.npz`：原始有符号96³体、90幅恢复相位投影、第一个角度恢复的记录面复场、角度和体素间距。
- `input-reference.npz`：输入参考体和归一化点云，只供比较。
- `metrics.json`：完整数值评价。
- `volume-comparison.png`、`phase-projections.png`、`volume-slices.png`、`reconstructed-rotation.gif`：图形结果。
- `index.html`：独立离线交互文件；`viewer-data.js`是相同数据的独立副本，HTML无需该文件即可打开。

```powershell
# 生成全息记录，并从保存的记录独立反演三维体
& .venv/Scripts/python.exe -m optics_sim.pointcloud_tomography
# 只读取已有结果，更新图表、GIF与离线交互页
& .venv/Scripts/python.exe -m optics_sim.pointcloud_viewer
```

角度数可用 `--angles` 修改；默认90。增加采样会增加计算量和磁盘占用。交互页面打开后不再进行光学反演，旋转和切片基于已经恢复的体数据。
