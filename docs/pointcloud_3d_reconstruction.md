# 从已保存全息数据估计三维点分布

本次读取 `outputs/pointcloud_direct/{cat,horse,wolf}/recordings.npz` 和标定文件，新增三维估计。PPT已删除二维照片、二维相位靶标、GS照片案例以及三幅平面重聚焦展示页，保留三组点云的记录/编码页，加入静态三维估计图。

## 三维结果的含义

每个结果都是由保存全息数据恢复的复场进行数值反演得到的**三维复散射体估计**，图中点为估计幅值体的局部峰。未将原输入点云直接重画为恢复结果，也没有重新进行90角度层析。结果依赖下面明确列出的薄点云和稀疏先验，不是单视角数据唯一确定的完整封闭实体。

当前三份源点云较薄。若不使用几何先验，直接深度扫描亮点或不受约束的稀疏反演会产生明显轴向拖尾与伪点。基础试算保存在 `volume-reconstruction/` 和 `sparse-reconstruction/`，最终PPT使用 `thin-prior-reconstruction/` 的结果。当前先验假设点云集中在一个主倾斜面附近，且竖直方向主面倾斜较小；对任意厚体或多层复杂遮挡物体，这个假设可能失效。

## 独立反演输入

`optics_sim.pointcloud_sparse.reconstruct()` 的输入为记录路径、标定路径、输出目录及通用算法参数。反演过程中不读取 `input-reference.npz` 或原PCD。

- **猫·光学离轴**：保存的振幅全息片乘共轭参考光，模拟物理4f光瞳选级，得到会聚场U*，取共轭统一为发散物光U。
- **马·计算全息**：保存的8位振幅、256级相位命令在理想双调制器中产生会聚场U*，取共轭统一为U。
- **狼·数字全息**：由保存的四帧16位干涉计数、曝光标度和参考振幅，经四步相移解调恢复U。

对光学、计算全息增加数值三维反演，是为了根据再现复场绘制三维图。这一数字分析步骤与其原有光学再现环节应分别理解。全部为计算机模拟，没有额外声称实物光学采集。

## 深度扫描与薄点云主面

1. 把带宽120 mm⁻¹内的复场采样到512²、2 μm网格，固定扫描2.5至3.5 mm的101个平面。这个扫描范围三组相同，不由真值深度最小值/最大值逐例裁定。
2. 每层计算I=|U|²，取横向高斯平滑σ=0.65与σ=3像素的正差作为局部聚焦对比度。这是本项目的启发式聚焦指标，不声称对所有密集相干物体都能准确定位。
3. 沿竖直方向累计对比度，归一化每个横向位置的深度响应。扫描主面 `z = c + a*x`：斜率a为−1.5至1.5，步长0.05；截距c为2.7至3.3 mm，步长10 μm。选择聚焦对比度积分最大的面。
4. 三维求解只允许该面**±120 μm**范围以及共同640 μm方形视场内的体素非零。±120 μm是显式算法先验，主面位置和倾角来自全息数据，未读取输入点的角度或轮廓作为支持域。

最终主面斜率/截距为：猫−0.75/3.000 mm，马−0.65/3.010 mm，狼−0.80/3.020 mm。它们是从全息数据估计的主面，不等同于完整物体表面。

## 复数稀疏反演

在41×256×256体素网格上估计复散射系数o。横向间距4 μm，轴向间距25 μm，深度仍覆盖2.5至3.5 mm。正向算子A将每一层复散射体作菲涅耳传播并相加，应用同一120 mm⁻¹光瞳。数据b为记录恢复的全息面复场。

目标为 `min_o 0.5 ||A o − b||₂² + λ ||o||₁`。复数L1范数为各体素复幅值的和，软阈值收缩幅值、保持相位。FISTA迭代250次，步长1/41，λ取初始伴随场最大幅值的0.015倍。三组使用同一组参数，未使用原点云调整点的位置、增益或支持域。

从最终幅值体提取3×3×3局部峰，阈值为估计体峰值12%，排除首末深度层。这只定义可读的点云导出；完整复散射体保留，未把输入点数3400强行作为输出点数。

单帧全息数据结合稀疏先验推断三维结构有文献依据，例如 [Brady等，Compressive Holography, Optics Express 17, 13040–13049 (2009)](https://doi.org/10.1364/OE.17.013040) 和作者的 [项目说明](https://disp.duke.edu/research/compressive-holography)。本代码使用复数稀疏反演思路，增加了明确的薄点云先验，不声称逐项复现文中实验和求解器。

## 结果与限度

| 案例 | 导出局部峰数 | 复场数据拟合相对残差 | 估计点到输入集合的最近邻距离中位数 | 输入点到估计集合的最近邻距离中位数 |
| --- | ---: | ---: | ---: | ---: |
| 猫·光学离轴 | 1245 | 7.65% | 27.9 μm | 13.2 μm |
| 马·计算全息 | 1441 | 7.46% | 26.0 μm | 14.3 μm |
| 狼·数字全息 | 1009 | 8.66% | 23.3 μm | 14.8 μm |

这些最近邻集合距离只是事后评价，不是逐点配对的定位RMSE。估计点中约53.0%、55.1%、58.0%分别落在源点集合30 μm内；仍有明显伪点或深度偏差。另一方向的小距离主要说明覆盖程度，不能据此宣称3400点准确恢复。三组物体不同，数值不可直接作为三种全息方式的性能排名。

主要限制包括单视角和有限带宽的轴向歧义、相干干涉、离散体素对连续点源模型的近似，以及先验和正则化导致的偏差。图中显示的是估计体局部峰，不是精确原点云，也不是闭合网格。PPT只展示静态视图，没有旋转动画。

## 文件与复现

每个案例的 `thin-prior-reconstruction/` 包含：

- `sparse-volume.npz`：完整复数估计体、坐标、估计点与幅值。
- `estimated-points.ply`：三维估计点，坐标单位米；可供三维点云软件查看。
- `reconstruction.json`：算法、先验、参数、拟合残差、迭代历史。
- `evaluation.json`：独立事后评价，反演不读取此文件。
- `presentation-views.png`：同一估计点集两个静态方向，用于PPT。
- `focus-scan/`：从相同全息数据计算的三维聚焦体和初始定位结果。

```powershell
$env:OPENBLAS_NUM_THREADS='4'
$env:OMP_NUM_THREADS='4'
& .venv/Scripts/python.exe -m optics_sim.pointcloud_sparse --case all --iterations 250
```

原点云与真值场只在 `run()` 完成反演后用于评价，不进入 `reconstruct()`。保留不加薄点云先验的基础试算，便于了解此先验对结果的影响。
