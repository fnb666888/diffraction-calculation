# 三维点云直接输入的三种全息模拟

当前PPT采用 `optics_sim.pointcloud_direct` 的结果，输出在 `outputs/pointcloud_direct/`。这是按用户澄清“点图作为输入，分别三种全息方式模拟”实施的点源法。此前90角度投影层析试算在 `pointcloud_holography` 目录，本次PPT不使用那一组数据。

## 输入与共同波前

猫、马、狼分别用于光学离轴全息、复振幅计算全息、相移数字全息。每组3400点，来源及许可见 `data/pointcloud_holography/`。PCL ISM教程注明这些模型借用自Ohio数据集：[教程](https://pointclouds.org/documentation/tutorials/implicit_shape_model.html)、[数据仓库](https://github.com/PointCloudLibrary/data)。

原始xyz按(y,z,x)映射为横向、竖直、深度，等比缩小使最长边为0.7 mm，再绕竖直轴旋转40°作为固定输入姿态，以便不同横向部位具有可辨的近远深度；中心深度为3 mm。每个点均作为相干点源，振幅相同，源初相位为0。图中点云颜色只代表深度，不指定光学振幅。建模保留每个点的连续xyz坐标，未把点云转换为单幅相位投影。

点源波前采用菲涅耳近似球面波直接叠加：

`U(x,y) = Σj [1/zj] exp{i k(zj−z0) + iπ[(x−xj)²+(y−yj)²]/(λzj)}`

其中z0=3 mm仅消去公共轴向相位，相对轴向相位仍保留。用可分离的x、y指数与矩阵乘法加速完整求和，没有深度分层量化，也没有WRP。本模型是近轴标量点源模型，未模拟遮挡、真实材料散射、反射或多次散射；不是完整电磁散射解。

波长632.8 nm，先在1024²、1 μm网格求和，物光统一经过120 mm⁻¹圆形带宽，然后以同物理窗口的频谱补零插值到2048²、0.5 μm记录网格。全息窗口宽1.024 mm，插值不是增加物光信息。直接点波的最大局部空间频率在标定中记录，检查低于原求和网格Nyquist；插值前已经带限。全息面复振幅按统一物光峰值归一。有限带宽会限制横向分辨率和深度分辨率。

## 三种记录与再现

### 猫：光学离轴全息

物光U与振幅1.5、水平载频400.390625 mm⁻¹的倾斜参考光R干涉，记录I=|U+R|²，理想薄振幅片t=I/max(I)。用共轭参考光R*照明，物理4f圆形光瞳选出与U*成正比的级次，向前传播到各物体深度，产生共轭实像光强。

这里FFT模拟光学选级与传播。光学再现函数只读取保存的全息片透过率和标定；校正使用已知参考强度与记录归一化系数，不用真值拟合。仿真满足3B<fc和2fc+B<Nyquist，Nyquist为1000 mm⁻¹。未模拟材料非线性、显影噪声和像差。

### 马：复振幅计算全息

数值求和点源波前U，取会聚场U*，将其振幅量化为8位、相位量化为256级，保存为调制命令。模拟平面波照明理想串联振幅与相位调制器，按实际量化后的出射场向前传播，在不同物体深度观察光强。

这是标准点源求和的复振幅CGH示例，假设可以独立调制振幅、相位。它与原PPT中的单平面GS纯相位编码示例不同；本例没有使用GS、双相位棋盘编码或WRP。最终再现只读取导出的振幅/相位命令与标定，不重新读取点云或目标复场。

### 狼：相移数字全息

物光与参考光叠加，参考相位取0、π/2、π、3π/2，记录四帧16位相机光强。按已知曝光标度还原光强，再由

`U = [(I0−Iπ) + i(Iπ/2−I3π/2)] / (4Ar)`

恢复全息面复振幅，按负距离数值菲涅耳传播到各物体深度。相移和参考振幅理想已知，没有光子噪声、读出噪声或相移误差。距离直接使用标定值，没有自聚焦。

## 静态深度重聚焦图

三个观察平面从输入深度的12%、50%、88%分位预设，属于已知深度扫描，不按恢复结果寻找最清晰位置。同一组全息记录或同一组CGH命令用于全部三个深度，没有在换平面时替换输入。

每幅图都是重建复场模平方，裁剪到相同640 μm方形物体区域。每组3幅图共享光强标度，统一γ=0.35提亮；没有逐图归一、平滑、原图覆盖或真值配准。颗粒纹理由相干点源干涉形成。图中的其他深度会出现离焦贡献，不能把一个观察平面误认为只包含该深度的点。

这些静态重聚焦图展示波前的深度信息，没有进行多角度层析或完整几何反演，也没有将源点云直接当成恢复三维体。PPT中没有加入旋转动画。

## 保存的数据与复现

- `recordings.npz`：光学片透过率／CGH振幅相位命令／四帧16位相机记录。
- `calibration.json`：采样、波长、参考光、带宽、距离及完整建模假设。
- `input-reference.npz`：输入点坐标与真值全息面物光，只用于参考和评价。
- `reconstructed.npz`：由保存数据恢复的全息面复场、三个深度的重聚焦复场和距离。
- `metrics.json`：全息面恢复复场相对L2误差。这不是三维几何恢复误差，也不用于三种方法排名。
- `pointcloud-input.png`、`focus-comparison.png`及其他静态阶段图：PPT使用的图。

```powershell
$env:OPENBLAS_NUM_THREADS='4'
$env:OMP_NUM_THREADS='4'
& .venv/Scripts/python.exe -m optics_sim.pointcloud_direct
```

`replay()`接口仅读取各目录的 `recordings.npz` 和 `calibration.json`。点云、真值场只进入正向生成和事后误差计算。
