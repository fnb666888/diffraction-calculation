# 泰伯效应（Talbot Effect）模拟：完整执行方案

> 本方案与《衍射计算计算机模拟执行方案》配套，直接复用其中的菲涅耳传播框架（Goodman《傅里叶光学导论》第 4、5 章方法）[pdf_9]，并衔接 CDI / 剪切干涉相关研究方向。

---

## 1. 项目目标

在已有的衍射计算模拟程序基础上，增加周期光栅自成像（泰伯效应）模拟模块，实现：

1. **光栅构造**：一维/二维振幅光栅（方波、正弦、占空比可调）与相位光栅；
2. **泰伯自成像验证**：在泰伯距离 $z_T$ 及其整数倍处重现光栅原像，在半泰伯距离处得到平移半个周期的像；
3. **演化可视化**：绘制 x–z 强度演化图，直观展示自成像的周期性重现；
4. **进阶模块**：分数泰伯效应（剪切干涉图样）与泰伯-劳厄干涉（双光栅莫尔条纹）。

核心认识：泰伯效应**不需要新算法**——它就是各衍射级次在自由空间传播中相对相位周期性重新对齐的结果，用已有的"菲涅耳传递函数法（双 FFT）"在多个 $z$ 平面采样即可完整重现 [pdf_9]。

## 2. 物理基础

### 2.1 泰伯距离

用单色相干平面波垂直照射周期为 $d$ 的光栅，在下游一系列特定距离处无需透镜即可重建光栅像：

$$z_T = \frac{2d^2}{\lambda}$$

- $z = n z_T$（$n$ 为正整数）：光栅原像完全重现；
- $z = z_T/2$：出现横向平移 $d/2$ 的像；
- 强度分布沿 $z$ 以 $z_T/2$ 为周期变化；
- 分数泰伯距离（如 $z_T/4$、$z_T/8$）上为带横向剪切和相位结构的干涉图样。

### 2.2 远场衍射级次（解析基准）

周期光栅的远场是分立衍射级，位置满足光栅方程：

$$\sin\theta_m = \frac{m\lambda}{d}, \quad m = 0, \pm1, \pm2, \dots$$

- 各级强度由光栅形状因子决定：二值方波振幅光栅按 sinc² 包络分布，$m=0$ 级最强，占空比 1:1 时偶数级消失；
- 级次总数约 $d/\lambda$；
- 光栅方程在模拟中的角色：**解析校核**（远场斑点位置必须与之一一对应）、**参数预判**（级次分离距离、所需 $z$ 与采样间隔）。

### 2.3 与已有框架的关系

- 传播计算：复用菲涅耳传递函数法 $H=\exp[-j\pi\lambda z(f_x^2+f_y^2)]$，谱相乘后逆变换 [pdf_9]；
- 抽样与补零约束、混叠检查、解析解对比的总体原则与主方案完全一致 [pdf_9]；
- 剪切干涉可测量空间相干性 [pdf_6]，2D 相位光栅干涉同样用于此目的 [pdf_6]；正交光栅分光 + 相位恢复的单次曝光叠层扫描成像（SSP）正是光栅衍射与 CDI 结合的实例 [pdf_2]。

## 3. 实施步骤

### 步骤一：参数设定

| 参数 | 建议值 | 说明 |
|---|---|---|
| $\lambda$ | 632.8 nm | He-Ne 激光 |
| $d$ | 20 µm | 光栅周期 |
| $z_T$ | $2d^2/\lambda \approx 1.27$ mm | 毫米量级，采样友好 |
| $\Delta x$ | $d/8 = 2.5$ µm | 须 ≤ $d/8$ 以分辨光栅，且 > $\lambda/2$ [pdf_9] |
| $N$ | 4096 | 总采样点数 |
| $M$ | ≥ 2048 | 光栅有效宽度内点数，光栅区须覆盖足够多周期 |

### 步骤二：构造光栅透过率

- 一维振幅光栅（方波，占空比可调）：$t(\xi)=\left[\cos(2\pi\xi/d)>0\right]$；
- 正弦型振幅光栅：$t(\xi)=\frac{1}{2}\left[1+\cos(2\pi\xi/d)\right]$（只有 0、±1 级）；
- 二维正交光栅：$t(\xi,\eta)=t(\xi)\cdot t(\eta)$；
- 相位光栅：振幅为 1，相位 = 光栅函数 × 2π（深度可调）；
- 光栅区横向覆盖足够多个周期并完整落入数组中央，边缘截断需通过补零区检查确认不产生伪影。

### 步骤三：多平面传播

对一系列观察距离 $z \in \{z_T/8,\ z_T/4,\ z_T/2,\ 3z_T/4,\ z_T,\ 2z_T\}$：

1. 生成补零光栅数组 $U_0$；
2. 对每个 $z$ 生成传递函数 $H(z)$；
3. $U_z=\mathrm{IFFT}[\mathrm{FFT}(U_0)\cdot H(z)]$；
4. 记录 $I_z=|U_z|^2$、振幅、相位。

### 步骤四：泰伯效应验证（定量判据）

| 检验项 | 判据 |
|---|---|
| $z = z_T,\ 2z_T$ | 强度与光栅原像的归一化相关峰 ≥ 0.99 |
| $z = z_T/2$ | 强度与 $t(\xi + d/2)$ 的相关峰最高（横移半周期） |
| 强度沿 z 的周期 | 自成像周期精确为 $z_T/2$ |
| 远场级次位置 | 衍射斑横向位置满足 $f_x = m/d$，与光栅方程一致 |
| 远场级次相对强度 | 方波光栅的偶数级消失、sinc² 包络与解析值吻合 |
| 数值收敛 | 增大 $M$ 与 $N$，直到各判据指标不再变化 [pdf_9] |

### 步骤五：可视化

1. **x–z 演化图**：对约 50–100 个 $z$ 值逐个传播，把各平面的横向强度剖面堆叠为伪彩色图——泰伯自成像的周期性重现一目了然；
2. **单平面三联图**：关键平面（$z_T/2$、$z_T$）输出强度/振幅/相位三联图（相位在模拟中直接读取）；
3. **远场图**：`fft2` 直接给出分立衍射级，用于光栅方程校核。

### 步骤六（进阶模块）

1. **分数泰伯效应 / 泰伯剪切干涉**：在 $z_T/8$、$z_T/4$ 等平面观察剪切干涉图样，并演示入射波前带微小曲率时图样的变化——此为泰伯剪切干涉仪测量波前/空间相干性的原理 [pdf_6]；
2. **泰伯-劳厄干涉（TLI）**：级联两片相同光栅，第二片置于第一片下游泰伯距离处；模拟入射平面波带微小曲率/倾斜时莫尔条纹的响应，体会其对波前畸变的极度敏感性；
3. **部分相干照明扩展**：用多模迭代表征部分相干入射（与 CDI 模拟中的部分相干处理思路一致），观察自成像衬度随相干长度的衰减。

## 4. 参考代码骨架（Python + NumPy）

```python
import numpy as np

# ---------- 参数 ----------
lam, d = 632.8e-9, 20e-6
zT = 2 * d**2 / lam            # 泰伯距离 ≈ 1.27 mm
dx, N, M = 2e-6, 4096, 2048    # dx <= d/8; M > 4*N_F 原则同样适用

# ---------- 1. 一维振幅光栅 ----------
xi = (np.arange(N) - N/2) * dx
g  = (np.cos(2*np.pi*xi/d) > 0).astype(float)   # 二值方波光栅
U0 = np.tile(g, (N, 1))                          # 沿 y 方向不变

# ---------- 2. 多平面菲涅耳传播 ----------
fx = np.fft.fftshift(np.fft.fftfreq(N, dx))
FX, FY = np.meshgrid(fx, fx)

zs = np.linspace(zT/8, 2*zT, 64)                 # x-z 演化扫描
for z in zs:
    H  = np.exp(-1j*np.pi*lam*z*(FX**2 + FY**2))
    Uz = np.fft.ifft2(np.fft.fft2(U0) * H)
    Iz = np.abs(Uz)**2
    phase = np.angle(Uz)                         # 相位直接可得
    # 收集各 z 的 Iz[:, N//2] 剖面 → 堆叠画 x-z 伪彩图

# ---------- 3. 定量验证 ----------
def corr(a, b):
    return np.sum(a*b) / np.sqrt(np.sum(a**2)*np.sum(b**2))

I_zT = np.abs(np.fft.ifft2(np.fft.fft2(U0) *
        np.exp(-1j*np.pi*lam*zT*(FX**2 + FY**2))))**2
print(corr(I_zT, U0))            # z=zT: 应 ≈ 1

I_half = np.abs(np.fft.ifft2(np.fft.fft2(U0) *
        np.exp(-1j*np.pi*lam*zT/2*(FX**2 + FY**2))))**2
print(corr(I_half, np.roll(g, N//2 - int(d/2/dx))))   # z=zT/2: 平移 d/2

# ---------- 4. 远场光栅方程校核 ----------
I_far = np.abs(np.fft.fftshift(np.fft.fft2(U0[:, N//2])))**2
# 衍射级应位于 fx = m/d 处; 1:1 方波光栅偶数级消失
```

## 6. 常见问题与注意事项

1. **抽样不足**：周期远小于普通孔径，$\Delta x$ 必须明显小于 $d$（建议 $d/8$），否则高级次折叠产生伪影；可先对单个周期做级次分析校核；
2. **光栅截断伪影**：光栅区域边界（非周期截断）会产生额外衍射，需通过补零区混叠检查确认；增大 $M$ 直到结果收敛 [pdf_9]；
3. **离散衍射级**：周期结构的频谱是离散的，远场斑点间距 $\Delta f = 1/d$ 是频率轴标定的天然校准点 [pdf_9]；
4. **光栅方程的角色**：不用于计算图样（图样由 FFT 全权给出），而是解析校核与参数预判工具；
5. **相位信息**：模拟中各平面相位均由 `np.angle()` 直接读取；做自成像机理分析时，观察各衍射级相对相位在 $z_T$ 处重新对齐的过程最为直观；
6. **与 CDI 的衔接**：分数泰伯平面的剪切干涉可用于测量照明相干性 [pdf_6]；正交光栅分光结构是单次曝光叠层扫描成像（SSP）等光栅-CDI 混合技术的基础 [pdf_2]。
