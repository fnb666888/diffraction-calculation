# 离轴全息计算机模拟：完整执行方案

> 本方案与《衍射计算计算机模拟执行方案》《泰伯效应模拟执行方案》配套，直接复用其中的菲涅耳传播框架（Goodman《傅里叶光学导论》第 4、5、11 章）[pdf_9]。

---

## 1. 项目目标

搭建离轴（利思-乌帕特尼克斯光路）全息的完整模拟程序，实现"记录—重现"闭环：

1. **记录模拟**：二维透明片物光 + 离轴参考光干涉，生成全息图强度 $I = |U_{ref} + U_{obj}|^2$——模拟中主动"只保留强度"，复现实验探测条件；
2. **重现模拟**：用原始/共轭参考波照明全息图，分别得到虚像与孪生实像；
3. **定量验证**：重现像与原物相关峰判定、0 级/±1 级分离条件、孪生像赝像特性；
4. **进阶模块**：相移数字全息（无孪生像的定量复振幅恢复）、像差补偿演示（共光路法 + 逆参考波法）。

核心认识：全息通过参考光干涉把物光的振幅和相位分别作为空间载波的幅度调制与相位调制记录下来，从而在"只能记录强度"的实验条件下直接、确定性地恢复波前，无需任何迭代相位恢复算法 [pdf_9]；这是它与 CDI（丢相位靠迭代找回）的本质区别 [pdf_3][pdf_8]。

## 2. 物理基础

### 2.1 记录公式

物体 $t(x_o,y_o)$ 置于记录面前 $z_o$ 处，物光 $\alpha(x,y)$ 为其衍射场；离轴参考平面波 $A\exp(-j2\pi\alpha y)$，载波空间频率 $\alpha = \sin 2\theta/\lambda$ [pdf_9]。记录强度：

$$I(x,y) = |A|^2 + |\alpha|^2 + A^*\alpha\, e^{j2\pi\alpha y} + A\alpha^* e^{-j2\pi\alpha y}$$

即"物光的振幅和相位分别作为频率为 $\alpha$ 的空间载波的幅度调制和相位调制被记录下来" [pdf_9]。

### 2.2 重现公式

全息图透过率 $t_H \propto I$，透射场分解为四项 [pdf_9]：

- $U_1, U_2$：直透光与 0 级（晕轮项）；
- $U_3 \propto |\!A|\!|^2 \alpha(x,y)$：**原物波前精确重现**（只差常数因子）→ 虚像；
- $U_4 \propto A^*\alpha^*$：共轭波前 → 会聚成孪生实像，其视差关系反转、"看上出由内向外" [pdf_9]。

离轴载波的作用：让 0 级、虚像（+1 级）、孪生像（−1 级）在频域/空间上分离；参考角必须足够大，否则孪生像与 0 级重叠 [pdf_9]。

### 2.3 像素代价与采样约束 [pdf_9]

- 离轴方向上全息图原则上需要 $4N$ 个像素（强参考下 $2N$），物体本身只需 $N$ 个——模拟网格须按此设置；
- 物面与全息面采样均须满足主方案的约束（$\Delta x > \lambda/2$、补零与混叠检查）[pdf_9]；
- 相移数字全息（同轴方案）只需 $N$ 像素，但至少四次曝光 [pdf_9]。

### 2.4 与直接衍射的关系（模拟中的意义）

对纯二维物体，重现的 $U_3$ 就是物体衍射场的原样回放，信息含量与直接衍射完全相同、无视差 [pdf_9]；全息模拟的意义在于复现"记录面只测强度"这一实验条件，并验证仅凭全息图就能无损找回复振幅——而普通衍射探测连相位都拿不到 [pdf_8][pdf_9]。

## 3. 实施步骤

### 步骤一：参数设定

| 参数 | 建议值 | 说明 |
|---|---|---|
| $\lambda$ | 632.8 nm | He-Ne 激光 |
| $z_o$ | 0.05 – 0.2 m | 物到全息面距离 |
| $\theta$ | 2° – 5° | 离轴参考角，须满足分离条件 |
| $\Delta x$ | 5 µm | 全息面采样间隔（> λ/2）[pdf_9] |
| $N$ | 4096（离轴方向 ≥ 4N_min） | 满足 4N 像素代价 [pdf_9] |
| 物体 | 2D 透明片，占 M×M 有效区 | 复用已有物体构造，边缘远离数组边界 |

分离条件检查：虚像载频 $\alpha$、0 级带宽 $B$、孪生像需满足 $\alpha \gtrsim 2B$ 量级，先解析估算再上模拟。

### 步骤二：构造物体与光路

1. 物体：二维振幅/相位透明片（复用主方案的圆孔、图片、字符等构造）；
2. 物光：用菲涅耳传递函数法把物面场传播 $z_o$ 到全息面 [pdf_9]；
3. 参考光：倾斜平面波 $A\exp(-j2\pi\alpha y)$，$|A| \ge |\alpha|$ 保证线性记录区 [pdf_9]。

### 步骤三：记录

$$I = |U_{ref} + U_{obj}|^2, \quad t_H = I / \max(I)$$

模拟中在此处主动丢弃复振幅、只保留强度，等效实验探测环节。

### 步骤四：重现（两次照明）

1. 虚像路径：$U_{recon} = U_{ref} \cdot t_H$，再反向传播 $-z_o$，取 $|U|^2$ 得虚像强度；
2. 实像路径：$U_{recon}' = U_{ref}^* \cdot t_H$，正向传播 $+z_o$，得会聚孪生实像 [pdf_9]；
3. 也可在频域用数字窗滤波 + 逆变换分离 ±1 级后重现。

### 步骤五：定量验证

| 检验项 | 判据 |
|---|---|
| 虚像 | 与原物 $\|t\|$ 的归一化相关峰 ≥ 0.99 |
| 孪生像 | 位于对称位置、为凹凸反转的赝像 [pdf_9] |
| 频域结构 | 全息图频谱中 0 级与 ±1 级清晰分离，级位置随 $\theta$ 线性移动 |
| 分离条件 | 逐步减小 $\theta$，观察 0 级与孪生像开始重叠的临界角 |
| 像素代价 | $N$ 不足（< 4N_min）时重现像出现伪影 [pdf_9] |
| 数值收敛 | 增大补零与 $N$，直到判据指标不再变化 [pdf_9] |

### 步骤六（进阶模块 A）：相移数字全息术 [pdf_9]

放弃离轴角，用同轴参考波，对参考相位步进 $\phi_R = 0, \pi/2, \pi, 3\pi/2$ 记录四幅全息图：

$$\phi = \arctan\frac{I_{3\pi/2} - I_{\pi/2}}{I_0 - I_\pi}$$

物光振幅由"屏蔽掉参考波"（如记录 $|U_{obj}|^2$）的强度图开方得到 [pdf_9]。验证：与真值逐像素比对，无孪生像、像素数最省；对相位畸变、随机相位屏等相位物体成像可完整恢复。

### 步骤七（进阶模块 B）：像差补偿演示 [pdf_9]

在物与全息面之间插入随机相位屏 $\exp[jW(x,y)]$（模拟大气/毛玻璃）：

1. **基线**：普通衍射成像，重现像被畸变搅坏；
2. **共光路法**：参考光同样穿过相位屏，记录 $|U_{obj}e^{jW} + U_{ref}e^{jW}|^2$——干涉项中畸变相位完全约掉，重现像完全恢复；此即共光路干涉测量术，已用于穿过地球大气对遥远物体成高分辨率像 [pdf_9]；
3. **逆参考波法**（静态介质）：记录时参考光绕开相位屏，重现时用 $U_{ref}^*$，畸变波共轭反向穿过同一介质逐点相消 [pdf_9]；
4. 对比三条路径，直观展示"保留完整波前 ⇒ 畸变可逆 ⇒ 可补偿"。

## 4. 参考代码骨架（Python + NumPy）

```python
import numpy as np

# ---------- 参数 ----------
lam, N, dx = 632.8e-9, 4096, 5e-6
z_o   = 0.1                       # 物到全息面距离
theta = 2 * np.pi/180             # 离轴参考角
alpha_c = np.sin(theta) / lam     # 载波空间频率

fx = np.fft.fftshift(np.fft.fftfreq(N, dx))
FX, FY = np.meshgrid(fx, fx)
H = lambda z: np.exp(-1j*np.pi*lam*z*(FX**2 + FY**2))

# ---- 1. 物体与物光 ----
x = (np.arange(N)-N/2)*dx;  X, Y = np.meshgrid(x, x)
t_obj = ...                        # 2D 透明片(复用已有物体构造)
U_obj = np.fft.ifft2(np.fft.fft2(t_obj) * H(z_o))   # 传到全息面

# ---- 2. 离轴参考光与记录 ----
U_ref  = np.exp(1j*2*np.pi*alpha_c*X)
I_holo = np.abs(U_ref + U_obj)**2   # 只保留强度(复现实验探测)
t_H    = I_holo / I_holo.max()

# ---- 3. 重现: 虚像 ----
U_recon = U_ref * t_H
U_img   = np.fft.ifft2(np.fft.fft2(U_recon) * H(-z_o))
img     = np.abs(U_img)**2

# ---- 4. 重现: 孪生实像 ----
U_recon2 = np.conj(U_ref) * t_H
U_img2   = np.fft.ifft2(np.fft.fft2(U_recon2) * H(+z_o))
img2     = np.abs(U_img2)**2

# ---- 5. 验证 ----
def corr(a, b): return np.sum(a*b)/np.sqrt(np.sum(a**2)*np.sum(b**2))
print(corr(img, np.abs(t_obj)**2))   # 应 ≈ 1
print(corr(img2, np.abs(t_obj)**2))  # 较低: 孪生像为赝像/散焦
```

## 6. 常见问题与注意事项

1. **0 级遮挡**：参考角过小导致孪生像落入 0 级晕轮，用频域图快速诊断；
2. **像素浪费**：离轴方案 $4N$ 像素代价是网格设置的第一约束 [pdf_9]，小网格模拟请改用相移方案 [pdf_9]；
3. **参考光强度**：$|A|$ 过小则记录非均匀、重现像失真；过强则全息图动态范围被晕轮占满，取 $|A| \sim |\alpha|$ 量级调试；
4. **模拟即全知**：模拟中相位随时可读（`np.angle`），做全息模拟时应主动"只保留强度"来复现实验条件，再验证无损找回 [pdf_9]；
5. **二维物体的极限**：纯平面透明片重现无视差，验证三维视差需引入多层堆叠物体或点源模型 [pdf_9]；
6. **与 CDI 的取舍**：全息需要相干参考光但重建直接确定；CDI 免参考光但依赖迭代算法与支集先验 [pdf_3][pdf_8]——两套模拟可共用同一物体和传播框架，方便对照。
