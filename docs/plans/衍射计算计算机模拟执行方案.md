# 衍射计算计算机模拟：完整执行方案

> 基于 Goodman《傅里叶光学导论》第 4、5 章 [pdf_9] 的衍射传播理论，并结合 CDI（相干衍射成像）相位恢复模拟的扩展需求整理而成。

---

## 1. 项目目标

搭建一套 Python 数值模拟程序，实现：

1. **物体构造**：小孔（圆孔）、方孔、单缝等几何孔径，以及任意灰度图片作为振幅/相位透过率物体；
2. **衍射传播**：覆盖远场（夫琅禾费）与近场（菲涅耳）两个区域的计算；
3. **结果验证**：与解析解对比，确认数值正确性；
4. **扩展模块**：丢弃相位、模拟"实验数据"，再运行迭代相位恢复算法，闭环验证 CDI 成像流程。

核心认识：**模拟即全知**。程序中每一步都是复数运算，复振幅 $U=Ae^{i\varphi}$ 全程可得，相位可通过 `np.angle()` 直接读取；相位丢失只发生在真实实验的强度探测环节，模拟中可以用"只保留强度"来人为复现这一环节。

## 2. 物理与算法基础

### 2.1 菲涅耳数：判断远近场的核心量

$$N_F = \frac{(l/2)^2}{\lambda z}$$

其中 $l$ 为孔径宽度，$\lambda$ 为波长，$z$ 为传播距离 [pdf_9]。

- $N_F \gtrsim 1$：菲涅耳（近场）衍射区；
- $N_F \lesssim 0.25$：基本进入夫琅禾费（远场）区；
- 示例：$\lambda=0.6\,\mu m$、孔径 2.5 cm 时，进入远场需 $z$ 达数百米量级——远场实验通常靠透镜焦面实现 [pdf_9]。

### 2.2 传播算法选型

| 方法 | 原理 | 适用场景 | 备注 |
|---|---|---|---|
| **A. 单次 FFT（夫琅禾费）** | 远场强度 = 孔径场傅里叶变换的模平方 | 远场 / 透镜焦面 | 最简单，第一步先跑通 [pdf_9] |
| **B. 菲涅耳变换法（单 DFT）** | 孔径场乘二次相位因子后做一次 FFT | 小菲涅耳数 | $N_F$ 小时最有效 [pdf_9] |
| **C. 菲涅耳传递函数法（双 FFT）** | 谱 × $H=e^{-j\pi\lambda z(f_x^2+f_y^2)}$ 再逆变换 | 任意近/中场 | **推荐首选** [pdf_9] |
| **D. 角谱 / 精确传递函数法** | $H=\exp\!\big[j\frac{2\pi z}{\lambda}\sqrt{1-(\lambda f_x)^2-(\lambda f_y)^2}\big]$ | 大衍射角、非傍轴 | 傍轴条件不满足时使用 [pdf_9] |

### 2.3 抽样与补零约束（数值正确性的关键）

- 孔径内有效样本数须满足 $M > 4N_F$ [pdf_9]；
- 精确传递函数法（方法 D）要求采样间隔 $\Delta x > \lambda/2$，否则补零区域发散 [pdf_9]；
- 补零比：$N = QM$，$Q \approx M/(4N_F)$，孔径置于 $N\times N$ 零场中央；
- 检验手段：在对数尺度强度图上检查图样边缘的旁瓣混叠，逐步增大 $M$、调节 $Q$，直到边缘混叠水平和图样形状不再变化 [pdf_9]。

## 3. 实施步骤

### 步骤一：构造物体透过率数组

物体表示为 $N\times N$ 复振幅透过率数组 $U_0(\xi,\eta)$，嵌入零场中央，孔径边缘远离数组边界（满足支集要求）。

- **几何孔径**：用 `rect`、圆盘等函数生成二值数组（圆孔、方孔、单缝等）[pdf_9]；
- **图片**：灰度归一化为振幅透过率（暗=0，亮=1）；若模拟纯相位物体，则令振幅为 1、相位 = 灰度 × 2π；
- 入射光默认为单位振幅平面波垂直入射。

### 步骤二：计算菲涅耳数并选择算法

按 §2.1 计算 $N_F$，据此选择传播方法；起步建议：先用方法 A 看远场图样，再切换方法 C 计算任意距离的近场演化。

### 步骤三：执行传播（以方法 C 为例）

按 Goodman 给出的流程 [pdf_9]：

1. 由 $\lambda$、$z$、孔径最大宽度 $R$ 计算 $N_F$；
2. 设定混叠判据（如图样边缘归一化强度 ≤ 10⁻⁴）；
3. 生成补零孔径数组（$N=QM$，中心置于下标 $(N/2,N/2)$）；
4. 生成传递函数数组 $H=\exp[-j\pi\lambda z(f_x^2+f_y^2)]$；
5. 对孔径场做 FFT，频谱中心移位后与 $H$ 逐元素相乘，逆 FFT，结果循环移位回中心；
6. 取模平方得强度 $I_z=|U_z|^2$。

### 步骤四：结果可视化

- 振幅图：`np.abs(Uz)`；
- **相位图：`np.angle(Uz)` —— 模拟中相位是计算副产品，直接读取即可**；
- 强度图：对数尺度 `log10(I + 1e-6)` 显示，便于检查边缘混叠与高阶衍射结构；
- 远场横向坐标换算：$x = f_x\lambda z$ [pdf_9]。

### 步骤五：验证

| 验证项 | 方法 |
|---|---|
| 方孔菲涅耳衍射 | 与菲涅耳积分解析解逐点对比，曲线应吻合 [pdf_9] |
| 圆孔远场 | 应得到艾里斑 |
| 轴上强度 | $N_F=10,100$ 等情形的光轴零点/泊松光斑特征可作交叉检验 [pdf_9] |
| 数值收敛 | 增大 $M$ 直到边缘混叠不再下降 [pdf_9] |

### 步骤六（扩展）：CDI 相位恢复闭环模拟

1. 由复振幅算出"实验数据"：$I = |U_z|^2$，**只保留强度、丢弃相位**；
2. 迭代相位恢复：每轮用 $\sqrt{I}$ 替换理论计算的振幅、保留计算所得相位，反传回物空间后施加支集约束（孔径外强制为零），如此往复直至收敛 [pdf_7]；
3. 由于真值相位已在模拟中记录，可逐像素比对恢复相位与真值，定量评估算法收敛性；
4. 可进一步比较不同算法（HIO 引入反馈机制避免陷入局部极小等）的收敛表现 [pdf_7]。

## 4. 参考代码骨架（Python + NumPy）

```python
import numpy as np
from PIL import Image

# ---------- 参数 ----------
lam = 632.8e-9      # He-Ne 波长
z   = 0.5           # 传播距离 (m)
dx  = 5e-6          # 物面采样间隔 (必须 > λ/2)
N   = 2048          # 总采样点数(补零后)
M   = 512           # 物体有效宽度内点数

# ---------- 1. 构造物体透过率 ----------
x = (np.arange(N) - N/2) * dx
X, Y = np.meshgrid(x, x)

# 方式A: 圆孔
aperture = (X**2 + Y**2 <= (100e-6)**2).astype(float)
# 方式B: 图片 (灰度归一化为振幅透过率)
# img = np.array(Image.open('mask.png').convert('L'), float) / 255
# aperture = 缩放到 M×M 后嵌入 N×N 零场中央

U0 = np.zeros((N, N), complex)
U0[aperture > 0] = 1.0            # 单位振幅平面波垂直入射

# ---------- 2. 菲涅耳传递函数传播 ----------
fx = np.fft.fftshift(np.fft.fftfreq(N, dx))
FX, FY = np.meshgrid(fx, fx)
H = np.exp(-1j * np.pi * lam * z * (FX**2 + FY**2))

Uz = np.fft.ifft2(np.fft.fft2(U0) * H)     # 频谱相乘再逆变换

# ---------- 3. 结果输出 ----------
Iz    = np.abs(Uz)**2              # 强度
phase = np.angle(Uz)               # 相位(模拟中直接可得)
amp   = np.abs(Uz)                 # 振幅

# 显示建议: plt.imshow(np.log10(Iz + 1e-6))  对数尺度检查边缘混叠

# ---------- 远场(夫琅禾费)一行实现 ----------
# I_far = np.abs(np.fft.fftshift(np.fft.fft2(U0)))**2
# 横向坐标: x_far = fx * lam * z
```

## 7. 常见问题与注意事项

1. **边缘混叠**：补零不足的直接表现，用对数尺度图检查，按 §2.3 调整 $M$、$Q$ [pdf_9]；
2. **采样违例**：方法 D 下 $\Delta x \le \lambda/2$ 会导致补零区发散 [pdf_9]；
3. **相位不是"丢失"而是"未记录"**：模拟中随时可读取；做 CDI 模拟时是主动丢弃相位以复现实验条件 [pdf_7]；
4. **单幅衍射强度解不唯一**：物体与其共轭反转给出相同强度，故相位恢复必须依赖支集等先验约束 [pdf_7]；
5. **物体支集**：物体须有清晰边界且远离数组边界，这是 HIO 类算法收敛的前提之一 [pdf_7]。
